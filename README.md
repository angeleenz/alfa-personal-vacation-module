# Модуль «Отпуск» для системы Альфа-Персонал

> Проект по системной аналитике, демонстрирующий полный цикл разработки требований: от анализа бизнес-требований до проектирования базы данных и формирования User Story Map.

---

## О проекте

Цель проекта — спроектировать модуль **«Отпуск»** для HR-системы **«Альфа-Персонал»**, который автоматизирует процесс оформления отпусков сотрудников.

В рамках проекта были проработаны функциональные требования, пользовательские сценарии, бизнес-процессы, UML-диаграммы, модель базы данных и пользовательские истории.

---

## Цели проекта

- автоматизировать процесс оформления отпусков;
- сократить объём ручной работы HR и бухгалтерии;
- обеспечить прозрачность согласования заявок;
- исключить потерю документов;
- интегрировать процесс с кадровой и бухгалтерской системами.
