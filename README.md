# Проектирование модуля «Отпуск» для системы «Альфа-Персонал»

> Портфолио-проект по системной аналитике, демонстрирующий полный цикл разработки требований: от анализа бизнес-требований до проектирования базы данных и формирования User Story Map.

---

## О проекте

В рамках проекта был спроектирован модуль **«Отпуск»** для HR-системы **«Альфа-Персонал»**.

Цель проекта — автоматизировать процесс оформления отпусков сотрудников: от создания заявки до согласования, расчёта отпускных и их выплаты.

В ходе работы были выполнены анализ бизнес-требований, разработка функциональных требований, моделирование бизнес-процессов, описание пользовательских сценариев, проектирование структуры базы данных и формирование пользовательских историй.

> **Все артефакты проекта успешно прошли проверку куратором курса (100/100).**

---

## Цели проекта

- автоматизация процесса оформления отпусков;
- сокращение ручной работы HR и бухгалтерии;
- повышение прозрачности процесса согласования;
- снижение количества ошибок и потери документов;
- интеграция с кадровыми и бухгалтерскими системами.

## Приобретённые навыки

В рамках проекта были применены следующие навыки системного аналитика:

- анализ и декомпозиция бизнес-требований;
- разработка функциональных требований;
- описание пользовательских сценариев (Use Case);
- моделирование бизнес-процессов в BPMN;
- построение UML-диаграмм;
- проектирование логической структуры базы данных;
- формирование User Story;
- приоритизация требований методом MoSCoW;
- подготовка проектной документации.

## Результаты

В результате выполнения проекта были подготовлены:

- Спецификация функциональных требований (FSD);
- 3 детализированных сценария Use Case;
- BPMN-диаграмма бизнес-процесса;
- UML Use Case Diagram;
- UML Activity Diagram;
- UML Sequence Diagram;
- ER-модель базы данных;
- User Story Map;
