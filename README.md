# Модуль «Отпуск» для системы Альфа-Персонал

> Проект по системной аналитике: анализ и проектирование модуля управления отпусками для корпоративной HR-системы «Альфа-Персонал».
>
> Выполнен в рамках курса «Системная аналитика» от Альфа-Банка.
>
> **Все артефакты проекта проверены куратором. Итоговая оценка — 100/100.** 

---

## О проекте

Цель проекта — разработка концепции модуля «Отпуск» для автоматизации процесса планирования, согласования и оформления отпусков сотрудников.

В рамках проекта был проанализирован текущий процесс оформления отпусков, выявлены требования к системе и разработаны аналитические артефакты, описывающие бизнес-процессы, взаимодействие пользователей и структуру данных.

---

## Роль в проекте

**Системный аналитик**

В рамках проекта выполнены следующие задачи:

- анализ бизнес-требований;
- разработка функциональных требований (FSD);
- выявление бизнес-правил и ограничений;
- подготовка уточняющих вопросов для заинтересованных лиц;
- моделирование бизнес-процесса в нотации BPMN;
- разработка Use Case сценариев;
- создание UML-диаграмм;
- проектирование ER-модели данных;
- формирование User Story Map и выделение MVP.

---

## Функциональность модуля

Модуль «Отпуск» позволяет сотрудникам:

- создавать заявки на отпуск;
- выбирать и изменять периоды отпуска;
- отслеживать статус заявки;
- получать уведомления о ходе процесса;
- просматривать отпуска коллег для планирования.

Руководители и HR получают возможность:

- рассматривать заявки сотрудников;
- согласовывать или отклонять отпуска;
- контролировать процесс оформления;
- передавать данные в смежные системы.

Система обеспечивает:

- автоматическое формирование заявления;
- подписание документов электронной подписью;
- хранение документов в электронном архиве;
- интеграцию с кадровыми и бухгалтерскими системами.

## Артефакты проекта

### 1. Анализ требований

Выполнено:

- анализ бизнес-требований;
- разработка функциональных требований;
- описание бизнес-правил;
- подготовка вопросов для уточнения требований.

Папка: `requirements`

---

### 2. Моделирование бизнес-процессов

Разработана BPMN-модель процесса **«Планирование отпуска»**.

Модель отражает взаимодействие:

- сотрудника;
- руководителя;
- HR;
- бухгалтерии;
- информационных систем.

Папка: `diagrams`

---

### 3. Use Case моделирование

Разработаны пользовательские сценарии:

- создание заявки на отпуск;
- согласование заявки руководителем;
- перенос утверждённого отпуска.

Включает:

- Use Case Diagram;
- спецификации Use Case.

Папка: `use_cases`

---

### 4. UML-моделирование

Созданы диаграммы:

- Use Case Diagram;
- Activity Diagram;
- Sequence Diagram.

Папка: `diagrams`

---

### 5. Проектирование данных

Разработана ER-модель базы данных модуля «Отпуск».

В рамках работы:

- выделены основные сущности;
- определены атрибуты данных;
- установлены связи между сущностями;
- определены первичные и внешние ключи.

Папка: `diagrams`

---

### 6. Планирование развития продукта

Создана User Story Map:

- сформированы пользовательские истории;
- выполнена приоритизация по MoSCoW;
- выделен MVP первого релиза.

Папка: `user_story_map`
