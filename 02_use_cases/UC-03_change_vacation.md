# UC-03. Перенос отпуска

## Цель

Позволить сотруднику изменить даты ранее согласованного отпуска.

## Актор

- Сотрудник

## Предусловия

- У сотрудника есть утверждённая заявка на отпуск.

## Основной сценарий

1. Сотрудник открывает заявку.
2. Выбирает действие **«Перенести отпуск»**.
3. Указывает новые даты.
4. Отправляет заявку.
5. Система проверяет корректность данных.
6. Руководитель получает уведомление.
7. После согласования статус заявки обновляется.

## Альтернативный сценарий

- Если новые даты некорректны, система отображает сообщение об ошибке.
- Руководитель может отклонить перенос.
