# UC-01. Создание заявки на отпуск

## Цель

Позволить сотруднику создать заявку на отпуск и отправить её на согласование.

## Актор

- Сотрудник

## Предусловия

- Пользователь авторизован.
- Пользователь имеет право на отпуск.

## Основной сценарий

1. Сотрудник открывает раздел **«Отпуск»**.
2. Нажимает **«Создать заявку»**.
3. Указывает тип и период отпуска.
4. Отправляет заявку.
5. Система проверяет корректность данных.
6. Заявка регистрируется.
7. Руководителю отправляется уведомление.

## Альтернативный сценарий

- Если выбранные даты недоступны, система отображает сообщение об ошибке.
- До отправки сотрудник может отменить создание заявки.
