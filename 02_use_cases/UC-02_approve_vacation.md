# UC-02. Согласование заявки на отпуск

## Цель

Позволить руководителю согласовать или отклонить заявку сотрудника.

## Актор

- Руководитель

## Предусловия

- Заявка находится в статусе **«Ожидает согласования»**.

## Основной сценарий

1. Руководитель открывает список заявок.
2. Просматривает информацию.
3. Принимает решение.
4. Система изменяет статус заявки.
5. Сотруднику отправляется уведомление.

## Альтернативный сценарий

- Руководитель может отклонить заявку с комментарием.
- При технической ошибке заявка переводится в статус **«На проверке»**.
